# GlucoTwin_AI_Virtual_patient
# Diabetes patients have health data from medical records and wearable devices, but this data is often not analyzed together. This makes it difficult to identify health changes early. Our project combines both data sources to predict the risk of a glucose spike in the next 2 hours.
# Healthcare Usage: GlucoTwin helps healthcare professionals monitor a patient's health data and identify the risk of a glucose spike early. It combines medical records and wearable data to provide a simple, real-time health overview.
# Technical Stack:-
Programming: Python
Data Processing: Pandas, NumPy
Machine Learning: Scikit-learn, Random Forest
Data Visualization: Plotly
Dashboard: Streamlit
Model Saving: Joblib
Data: Synthetic EHR & Wearable Data
Version Control: GitHub
# AI/ML Model or Framework Details
Model: Random Forest Classifier
Purpose: Predict the risk of a glucose spike within the next 2 hours
Framework: Scikit-learn
Input: EHR + wearable data
Output: Low, Moderate, or High glucose-risk prediction
Model Evaluation: Accuracy, Precision, Recall, F1-score
Explainability: Feature importance to identify important factors influencing the prediction
